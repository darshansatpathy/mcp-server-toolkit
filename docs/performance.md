# Performance

Generated by `python bench/load.py --clients 32 --calls 100`: one uvicorn worker, SQLite in WAL mode, Streamable HTTP in stateless JSON mode, every call carrying an RS256 token verified on the request. 32 concurrent clients across 4 tenants; 20% creates, 40% gets, 40% full-text searches.

**3200 tool calls in 14.2 s: 225 calls/s**, 0 errors.

| all | 3200 | 123.7 | 200.5 | 382.6 |

Mean 134.9 ms. Latency here includes the 32 clients' own work: clients and server shared one two-core machine that was also running other jobs, so treat these as a floor, not a ceiling.

## Limits hold under a burst

One principal sending 200 reads back to back against the default limit (120 a minute, bucket of 120): **121 allowed, 79 refused** with a retry-after (the bucket of 120, plus what refilled during the burst).

Scale-out: run more replicas behind a load balancer with `MCPKIT_REDIS_URL` set, so every replica draws from one bucket per principal, and move the store to your real database.
